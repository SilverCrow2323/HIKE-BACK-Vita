# FAQ

## Does the VPK contain the original PC game?

No. Install the Vita port, then copy the original game's `game/` folder separately.

## Where does the content folder go?

`ux0:/app/RENPYHIKE/game/`

## Do I have to use the VitaShell folder installation method?

The repository recommends extracting the VPK as an archive and using VitaShell **TRIANGLE → More → Install folder** because direct VPK installation may be slow.

## Where do I get the original game?

Use the official source: [HIKE BACK Vita original game](https://clowndream.itch.io/hikeback).

## Where should I report a problem?

Open an issue in the [port repository](https://github.com/SilverCrow2323/HIKE-BACK-Vita/issues). Include the exact path, port version and reproducible steps; do not upload the original game files.
